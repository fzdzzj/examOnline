# examOnline —— 关键场景决策记录（v1.0）

> **编制日期**：2026-09-10
> **性质**：需求规格说明书的补充，明确"同一事件不同情况"的处理策略
> **状态**：已与产品负责人逐项确认

---

## 一、交卷与时间边界

### 1.1 交卷时间冲突（倒计时归零瞬间点交卷）
- **决策**：以**服务端时间为准**。前端倒计时仅作展示，交卷时后端校验服务端时间戳；判定超时则按"超时自动交卷"处理。
- 依据：前端时间不可信（可篡改），《需求规格说明书》§5.1。

### 1.2 重复交卷（双击/网络重试）
- **决策**：**幂等处理，首次为准**。`exam_id + student_id` 唯一约束（uk_exam_student），重复交卷请求直接返回首次提交结果，不覆盖、不新增记录。

### 1.3 手动交卷后反悔
- **决策**：**不可反悔**。交卷即终稿，与"幂等首次为准"一致；学生漏题不提供撤回，可事后走成绩复核流程。

### 1.4 迟到学生剩余时间
- **决策**：**按时间窗截断**。剩余时间 = min(个人时长, 距时间窗结束剩余时间)，保证所有答卷在时间窗内结束。迟到允许分钟数由 `allow_late_minutes` 控制。

### 1.5 教师提前结束考试
- **决策**：教师点"结束" → 未交卷学生按**最后自动保存的答案强制交卷**，不另行作废、不延长作答。

## 二、断线与故障恢复

### 2.1 断网 + 本地倒计时归零
- **决策**：**本地归零即锁定**。前端本地倒计时归零后锁定答题界面并标记"待同步"，网络恢复后按锁定状态提交；服务端仍以服务端时间兜底校验。

### 2.2 浏览器崩溃 / 误刷新
- **决策**：**自动保存续考**。30 秒自动保存 + 崩溃前最后状态落本地，重新进入恢复最后保存的答案，个人倒计时按已消耗时间继续（不暂停）。

### 2.3 服务器宕机恢复（自定义补充）
- **决策**：**自动保存续考 + 补偿时间 + 前端本地缓存配合**：
  1. 前端本地（IndexedDB）持续缓存待同步答案，宕机期间作答不丢失；
  2. 服务恢复后前端自动同步本地缓存，更新自动保存；
  3. 为受影响学生**延长等量时间**（宕机 10 分钟补 10 分钟），由后端记录宕机时间窗并统一顺延个人截止时间。

### 2.4 离线答案冲突（多设备/多端同步）
- **决策**：沿用 §5.1 规避方案——`version` 版本号 + 时间戳，**以最新版本为准**，冲突时丢弃旧版本并记录日志。

## 三、防作弊

### 3.1 切屏检测达到阈值
- **决策**：**只警告 + 记录，不强制交卷**。切屏事件全部落 `exam_behavior_logs`，前端弹警告；是否作废答卷由教师事后依据行为日志判定。
- 说明：文档 §7.3"强制交卷"**不启用**，避免误伤。

### 3.2 多设备登录进入考试
- **决策**：**踢掉旧会话**。新设备进入考试后旧设备会话立即失效（Redis 会话强制下线），防止一账号双端作答。

### 3.3 人脸识别失败 / 无摄像头
- **决策**：**教师人工放行（实时审批 + 无人时降级存档）**：
  1. 优先走教师后台实时审批；
  2. 考试进行中教师不在线时，自动降级为**拍照存档**进入考试，考后由教师抽检复核；
  3. 不采用"识别失败禁止进入"的严格模式。

### 3.4 随机抽题 / 选项乱序的稳定性
- **决策**：**进入时锁定一次**。进入考试时抽题 + 乱序并锁定，刷新、断线重进均不重新抽取，防止"刷新刷题"。

## 四、考试中试卷变更

### 4.1 考试进行中教师修改试卷
- **决策**：**锁定试卷，禁止修改**。考试开始后试卷冻结（改题/删题/改分值均不允许）；修改只能在考试结束后进行，且只影响后续场次。
- 延伸：考试结束前若发现题目有误，走 §5.2 错题补偿流程。

## 五、成绩管理

### 5.1 补考/缓考成绩规则
- **决策**：**按考试配置，提供规则选项**：教师发布补考/缓考时选择该场次的成绩规则——
  - 取最高分
  - 取最近一次
  - 取平均分
- 所有历史成绩记录保留，不覆盖删除。

### 5.2 客观题答案有误的补偿（发布后）
- **决策**：**修正答案重新判分**。流程：撤回已发布成绩 → 教师修正标准答案 → 重新判分（客观题全量重算）→ 重新发布。与该题相关的学生成绩以新判分为准。
- 备选方案（未选）：废题全员加分、人工逐个处理。

### 5.3 成绩发布后撤回
- **决策**：**撤回后学生端隐藏成绩**，状态回到"已批改"，学生端显示"成绩待发布"；所有撤回操作留审计日志（谁/何时/原因），撤回需管理员权限。

### 5.4 成绩复核期间学生端显示
- **决策**：**复核中隐藏成绩**。学生提交复核申请后，其成绩在学生端锁定隐藏、显示"复核中"；复核完成（重新批改/调整分数）后更新显示。防止"看了分数再申请"。

## 六、技术实现要点（由上述决策推导）

| 决策 | 实现要点 |
|---|---|
| 服务端时间为准 | 交卷/超时校验一律用后端时钟；Redis 记录开始时间戳 |
| 幂等交卷 | `uk_exam_student` 唯一索引；重复请求返回首次结果（200 + 已存在标记） |
| 本地归零锁定 | Service Worker + IndexedDB 本地状态机：作答中 → 已锁定待同步 → 已同步 |
| 宕机补偿 | 后端记录宕机窗口 → 受影响学生个人截止时间统一顺延；前端本地缓存全量答案 |
| 踢旧会话 | Redis 会话表存 `session_id`，新会话进入时使旧 session 失效 |
| 人脸降级 | 审批接口 + 自动降级开关；降级记录单独标记，考后抽检队列 |
| 锁定抽题 | 进入考试时生成 `exam_paper_snapshot`（快照表），后续一律读快照 |
| 错题修正重判 | 判分引擎支持"按题目重算"：撤回发布 → 改答案 → 重跑客观题判分 → 重发布 |
| 复核隐藏 | `exam_submissions.status` 增加"复核中"状态；学生端按状态过滤显示 |

## 七、第三轮决策（2026-09-10 补充）

### 7.1 宕机补偿范围
- **决策**：仅补偿**正在作答中**的学生（已点"开始考试"且未交卷），未进入者不受影响。

### 7.2 错题修正重判范围
- **决策**：**仅客观题全量重算**，主观题教师批改结果不动。

### 7.3 踢旧会话确认
- **决策**：新设备弹"检测到已有会话，是否接管？"**确认弹窗**，确认后旧会话失效；防误触。

### 7.4 填空题判分
- **决策**：**归一化精确匹配**。答案去首尾空格、全半角统一、大小写不敏感后精确匹配；多空分别判分，各空分值均分。

### 7.5 主观题批改未完成
- **决策**：**允许发布 + 整体标记"部分批改"**。未批题目按 0 分计入总分，学生端可见"部分批改"标记，学生可走成绩复核。

### 7.6 监控中处置作弊
- **决策**：教师可**强制交卷 + 标记"异常待查"**。该答卷成绩暂不发布，查证后由教师定夺（正常/扣分/作废）。

### 7.7 删除考试
- **决策**：**软删除 + 状态限制**。未开始可删；已发布/已结束必须先撤回或归档；历史答卷保留（is_deleted）。

### 7.8 考后即时解析
- **决策**：**默认延迟发布，按考试可配置**。默认成绩发布后学生才可见错题解析，防答案泄露给未考学生。

### 7.9 开始计时方式
- **决策**：**点击"开始考试"才计时**。学生经过考前核验/说明页点击开始后启动个人倒计时；仅进入考试列表不计时。

### 7.10 答卷回看权限
- **决策**：**成绩发布后**学生可回看自己的试卷、答案与每题解析。

## 八、第四轮决策（2026-09-10 补充）

### 8.1 客观题即时出分
- **决策**：**按考试配置**。发布考试时教师选择"交卷即显示客观题分"或"全部批改后统一出分"。

### 8.2 补考对象确定（自定义）
- **决策**：**教师按分数筛选后指定**。教师可先按成绩条件筛选学生（如低于某分数线/缺考/未交卷），再勾选指定进入补考名单。

### 8.3 选做题计分
- **决策**：**选做答对加分**。选做题不计入必答总分，学生选做且答对额外加分；需防止总分超过满分（超满分按满分封顶，或按考试配置处理）。

### 8.4 成绩导出内容
- **决策**：四种导出全做：**全班成绩单、逐题得分明细、题目统计表（答对率/难度/区分度）、个人成绩单**。

### 8.5 错题本归集范围
- **决策**：**全部考试类型**（正式考试+随堂测验+练习）的错题都归集，支持按考试类型过滤。

### 8.6 学生账号来源
- **决策**：**管理员 Excel 导入 + 初始密码**，预留教务同步接口。

### 8.7 教师权限边界
- **决策**：**仅本人课程/班级 + 管理员授权**。跨班级查看/批改需管理员显式授权。

### 8.8 通知渠道
- **决策**：**站内信 + 微信模板消息**双通道。

### 8.9 多选题判分
- **决策**：**漏选给部分分、错选/多选 0 分**；部分分比例按考试配置。
- **实现注记（2026-09-10）**：部分分系数"按考试配置"需 exams 表加字段，属考场次结构变更。阶段 6（add-grading-score）首版采用**全局默认系数 1.0**，不改 exams 表；场次粒度配置作为后续变更 `add-partial-score-config` 单独落地。

### 8.10 缺考定义
- **决策**：**时间窗结束仍未点击开始 = 缺考**，记录缺考状态；缺考学生可被教师筛选后指定补考。

## 九、第五轮决策（2026-09-10 补充）

### 9.1 人脸识别频率（重要分歧点，见 §9.11）
- **决策**：**仅考前核验一次**，考中不抽拍。隐私友好、体验好，但防替考能力弱于文档 §5.2 的"每 5 分钟+异常抽拍"方案。

### 9.2 设备/IP 限制
- **决策**：**记录 + 报警不阻止**。记录设备指纹/IP 展示给教师，异常时报警（行为日志高严重度），但不硬性阻止/不强制交卷。

### 9.3 浏览器锁定强度
- **决策**：**全屏 + 禁用复制/右键**。不拦截开发者工具（易误伤且可绕过）。

### 9.4 行为日志可见性
- **决策**：**仅教师可见**。教师端可按事件类型/严重度筛选，查看全班行为时间线；学生不可见。

### 9.5 排行榜与隐私
- **决策**：**默认关闭**，教师发布时可开启；开启时仅**匿名显示前 10 名**。

### 9.6 口语题流程
- **决策**：录音上传 → 自动转文字 + AI 初评 → 教师复评确认；无 AI 能力时降级为纯人工听评。

### 9.7 代码题判分
- **决策**：**隐藏用例全判**。教师配置输入/输出/时间限制，正式测试用例对学生隐藏，防调试刷分；仅展示示例用例。

### 9.8 判分异常处理
- **决策**：判分失败（沙箱超时/解析失败/数据损坏）标记"**判分失败**"，教师可重判或手动给分，不影响其他学生。

### 9.9 消息通知时机
- **决策**：四类通知全做：**考前提醒**（提前 N 分钟，默认 30）、**成绩发布提醒**、**缺考/异常通知教师**、**流程性通知**（补考名单确定/复核结果）。渠道：站内信 + 微信模板消息。

### 9.10 成绩可见性
- **决策**：**学生仅见自己成绩**；教师可见全班并可导出。不做全班匿名可见。

### 9.11 待确认：人脸策略取舍
- 选"仅考前一次"意味着考中换人无法被系统发现。请确认接受此取舍，或改用折中方案：
  - **方案 A（已选）**：仅考前核验，考中零抽拍 —— 隐私最好，防替考靠自觉/现场监考；
  - **方案 B（折中）**：考前核验 + 考中低频抽拍（如每 15-20 分钟 1 次，可配置），异常行为触发即时抽拍；
  - **方案 C（文档原案）**：每 5 分钟 + 异常即时，威慑最强。
- 若维持 A，建议保留"抽拍"接口能力，后续可平滑开启。

## 十、第六轮决策（2026-09-10 补充）

### 10.1 人脸策略取舍（终定）
- **决策**：**维持"仅考前核验"**，考中零抽拍；保留抽拍接口能力，后续可平滑开启。防替考靠自觉 + 现场监考 + 设备/IP 报警。

### 10.2 离线模式范围
- **决策**：**教师按考试配置**（发布时勾选"允许离线"，默认允许）；离线答案落 IndexedDB，恢复后同步（版本号+时间戳）。

### 10.3 监考大屏内容
- **决策**：在线/离线/已交卷人数、答题进度、异常高亮（切屏/设备变化/人脸异常），点击查看学生行为时间线。

### 10.4 草稿纸（画板）
- **决策**：内置 Canvas 画板，手写演算保存为图片**附在答卷中**，教师批改/争议时可查看。

### 10.5 微信扫码登录
- **决策**：**首次扫码自动创建账号并绑定**，后续扫码即登录；需校验实名信息一致性。

### 10.6 账号安全
- **决策**：连续 5 次密码错误**锁定 15 分钟** + 找回密码（邮箱/管理员重置）。

### 10.7 成绩复核限制
- **决策**：每场考试**限申请 1 次**，成绩发布后 **7 天内**可申请，超期不可。

### 10.8 A/B 卷
- **决策**：**延后到 V2**。MVP 先做选项乱序 + 随机抽题，A/B 卷分配机制（进入时随机锁定）V2 实现。

### 10.9 题目查重
- **决策**：录入/导入时相似度比对，命中标记"**疑似重复**"由教师人工确认，不自动拒绝。

### 10.10 试卷快照
- **决策**：**考试发布时生成试卷快照**；答卷、判分、回看一律读快照，之后改题不影响已考场次。

## 十一、第七轮决策（2026-09-10 补充）

### 11.1 题目分值覆盖
- **决策**：**试卷内覆盖**（paper_questions.score 覆盖题库默认分），改试卷内分值不影响题库默认值，互不干扰。

### 11.2 试卷模板版本
- **决策**：**版本管理 + 回滚**。模板每次修改生成新版本，可查看历史并回滚；已发布考试绑定具体版本（配合快照）。

### 11.3 蓝图组卷
- **决策**：**MVP 即做**。教师填知识点×难度矩阵，系统按比例抽题，超出题库容量时提示教师调整。

### 11.4 标签结构
- **决策**：**扁平标签多选**（学科/难度/题型/自定义），建题时可多选。

### 11.5 题目软删除
- **决策**：**软删除 + 快照隔离**。已被快照引用的题删除后历史答卷仍可查看，仅新组卷不可用。

### 11.6 成绩排名并列
- **决策**：**并列同名次**（1,2,2,4）。

### 11.7 题目质量分析时机
- **决策**：考试批改**发布后自动生成**题目统计（难度/区分度/选项分布），教师端随时可看。

### 11.8 分析报告形式
- **决策**：**Web 在线报告（图表交互）+ 一键导出 PDF** 双形式。

### 11.9 错题重练
- **决策**：**错题本内直接重练**（答题→判分→更新归集状态），连续 3 次做对自动移出。

### 11.10 练习模式
- **决策**：学生**自选题目/标签组练习卷**，不计入成绩、可看解析，与考试独立。

## 十二、第八轮决策（2026-09-10 补充）

### 12.1 考试列表组织
- **决策**：**状态分组 + 时间排序**。待考→进行中→已完成分组，组内按开始时间近→远。

### 12.2 答题导航
- **决策**：**左侧题号导航面板**，已答/未答/标记三色标识可跳转；交卷前提示未答题目数。

### 12.3 听力题播放
- **决策**：每题独立音频，**限次重播（默认 2 次，可配置）**。

### 12.4 考试工具
- **决策**：**极简不做**。答题界面不做计算器/标记备注等工具。
- ⚠️ 与 §10.4 草稿画板存在冲突，见 §13.1 待确认。

### 12.5 补考数据建模
- **决策**：**独立考试记录**。补考是独立考试（独立时间窗/时长/规则），与主考互不影响，成绩按 §5.1 规则计算。

### 12.6 学生转班
- **决策**：**转班成绩随人**。历史成绩跟随学生个人，不影响已发布考试；报表按当前班级统计。

### 12.7 批量导入容错
- **决策**：**容错 + 错误报告**。逐行校验，错误行跳过并生成报告（行号+原因），正确行入库。

### 12.8 账号禁用
- **决策**：**软禁用可恢复**。禁用后无法登录，不影响历史数据，留审计日志；管理员可恢复。

### 12.9 学期/课程/班级
- **决策**：管理员建**学期→课程→班级**层级，教师绑定授课班级，考试绑定课程+班级。

### 12.10 成绩单格式
- **决策**：**Excel + 打印版 PDF**。Excel 为主，PDF 含题头/签名栏，个人成绩单可打印下发。

## 十三、项目定位收敛（面试版）

- **定位**：个人面试项目，展示单体架构应对 5000 人在线考试的完整能力。
- **范围**：核心闭环 + 3 个技术亮点，砍掉非核心模块（详见《面试版实施方案.md》）。
- **架构**：**单体 Spring Boot + MySQL 主从 + Redis + RabbitMQ**。
- **容量论证**：5000 人峰值在"开考拉卷（读，Redis 缓存扛）"与"交卷落库（写，MQ 削峰 + 批量插入 + 幂等唯一键扛）"，单体 + 主从 + 缓存 + 队列足够；分库分表/微服务留作面试扩展讨论点。
