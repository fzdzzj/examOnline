## 纪律

1. 串行队列顺序不可倒置；候选池无顺序承诺，立案先后由用户裁决。
2. 每案独立走三件套立项（`spec/changes/<change-id>/`），业务代码变更采用「先复核后收口」形态。
3. 案件闭环后：`spec/README.md` 归档表登记 + 本文件对应行状态更新（同笔或紧随）。
4. 本文件只登记功能待办与状态；不承载用例计数、门禁数值等易变事实，需要数值时现场跑命令取证。
