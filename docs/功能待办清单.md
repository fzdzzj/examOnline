### B.1 候选特性设计备忘（只读侦察沉淀，零 DDL 预研）

1. **题库批量标签管理（Batch Tagging & Untagging）**：
   - 后端：`POST /api/questions/batch-tags`，支持 `action` 为 `BIND`（追加打标，内存差集幂等插入）或 `UNBIND`（解绑剥离，物理删除指定关联），严格执行 `OwnershipGuard.assertOwner` 教师所有权校验；
   - 前端：`questions/index.page.vue` 勾选题目后弹出 `BatchTagModal`，支持按分类多选标签并切换「追加/移除」模式；
   - 依赖：复用既有 `question_tags` 表与 `uk_question_tags(question_id, tag_id)` 唯一索引，零 DDL。
2. **试卷分值智能配平（Paper Score Balancing）**：
   - 算法：离散最大余数保和算法。以 0.5 分为步长整数化（$T = S_{target} / 0.5$），整除得基础分 $Q = \lfloor T / N \rfloor$，余数 $R = T \pmod N$ 分配给前 $R$ 题各加 0.5 分，数学上恒等满足 $\sum = S_{target}$，单题下限 $\ge 0.5$ 分；支持按题型固定分值并将其余题型一键均分配平；
   - 后端：`POST /api/papers/{id}/questions/scores/rebalance`，单事务批量更新 `paper_questions.score`；
   - 前端：`papers/[id].page.vue` 增加「⚡ 分值智能配平」弹窗，双 Tab（一键均分 / 按题型配比）实时预览与一键应用；零 DDL。
3. **试卷按标准题型一键重排**：
   - 前端试卷详情页提供一键按「单选 $\to$ 多选 $\to$ 判断 $\to$ 填空 $\to$ 简答」标准题序重排，复用既有 `PUT /api/papers/{id}/questions/order` 端点一次性提交更新。
4. **考务监考与阅卷批改体验打磨**：
   - 题目快速复制：题库列表增加「复制」操作，深拷贝表单并自动加「（副本）」前缀打开新建模态框；
   - 监考大屏多维筛选：姓名/学号搜索框，点击顶部指标卡（在线/离线/异常）作为 Filter Tag 联动过滤，增加手动立即刷新按钮与下次轮询倒计时；
   - 主观题流水线批改：分值框按 Enter 直接提交并自动聚焦下一位学生，提供快捷给分 Tag（满分/及格/零分）与常用评语模板气泡。
5. **学生作答全景体验与防漏答**：
   - 疑难标记（Mark for Review 🚩）：答题卡右上角打旗标，导航格呈橙色标记并持久化在会话存储；
   - 交卷防漏答：交卷弹窗在 `unansweredCount > 0` 时提供「一键跳转至首道未答题」快捷定位。
6. **考前设备就绪自检与草稿画板**：
   - 考前就绪自检：网络往返时延（RTT Ping）、屏幕分辨率/全屏特性、浏览器内核兼容性检测，生成就绪报告并门控开考；
   - Canvas 悬浮画板：鼠标/触摸手写演算，支持粗细颜色调节与一键清空，作答会话内保留草稿。
