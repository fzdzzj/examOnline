# score-management 规范差异：题目统计导出的内存归因与条件优化

> 仅 GO 且实现、同负载复测与唯一门禁均通过时合入；NO-GO 原样归档为未采用草案。

## MODIFIED Requirements

### Requirement: 成绩导出

WHEN 教师导出成绩,

系统 SHALL 提供全班成绩单、逐题明细、题目统计、个人成绩单，且 SHALL 以流式方式防止大数据量内存溢出。对于题目统计，系统 SHALL 在保持既有统计及导出单元格口径的前提下，限制随答卷人数与题目数增长的全量逐题中间数据持有；SHALL NOT 以无界重复查询或不可接受的临时文件代价换取该内存下降。

#### Scenario: 全班成绩单导出

GIVEN 教师请求导出

WHEN 导出完成

THEN 生成含每人分数与排名的 Excel

#### Scenario: 大数据量不溢出

GIVEN 数千条成绩记录

WHEN 系统导出

THEN 采用流式写入

AND 不因内存不足失败

#### Scenario: 题目统计的内存增长与语义等价

GIVEN 本场存在多道题、已汇总答卷和可解析/损坏答卷，且总分可能并列

WHEN 教师导出题目统计

THEN 题序、平均分、得分率、答对率、作答人数及区分度与既有口径一致

AND 区分度仍按总分降序、并列时原先的稳定次序取前后各 floor(n×0.27) 组，少样本仍显示「样本不足」

AND 大样本导出不因无界逐题中间数据持有导致内存溢出，同时不得通过无界重复查询或不可接受的临时盘增长转移故障
