## 新增 path（4 条，类级 exam:manage）

| path | operationId | 说明 |
|---|---|---|
| `POST /api/admin/reconciliation/run` | `runReconciliation` | 手动触发对账（body 可带 examId） |
| `GET /api/admin/reconciliation/runs` | `reconciliationRuns` | 运行历史分页（page/size/examId） |
| `GET /api/admin/reconciliation/diffs` | `reconciliationDiffs` | 差异票分页（page/size/runId/diffType/status） |
| `POST /api/admin/reconciliation/diffs/{id}/close` | `closeReconciliationDiff` | 人工关闭差异票 |

## 新增 schema（8 个）

`ReconciliationRunRequest`、`ReconciliationRunResponse`、`ReconciliationDiffCloseRequest`、
`ReconciliationDiffResponse`、`ApiResponseReconciliationRunResponse`、

  `src/api/axios/{sdk.gen.ts,types.gen.ts,index.ts}` 三文件更新；
- 生成函数名与 operationId 一致：`runReconciliation` / `reconciliationRuns` / `reconciliationDiffs` /
  `closeReconciliationDiff`（避开 `run` 这类与既有 operation 撞名的泛化名）；
- 契约类类型零手写：前端页面只 import 生成的函数与 `ReconciliationRunResponse` /
  `ReconciliationDiffResponse` 类型。
