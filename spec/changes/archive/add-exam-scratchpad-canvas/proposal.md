# Proposal: add-exam-scratchpad-canvas（考试中在线草稿纸 / Canvas 演算画板，S 级纯前端特性）

## 1. 为什么做（背景与动机）

依据 [`docs/examOnline需求规格说明书.md`](../../docs/examOnline需求规格说明书.md) §3.3「体验创新 - 考试中草稿纸」与 [`docs/功能待办清单.md`](../../docs/功能待办清单.md) 候选池行 40：
- **痛点**：学生在参与数学、物理、理化、计算机算法与复杂综合逻辑类考试时，普遍需要推演公式、列方程式、绘制草图或推导中间步骤。在线考试若仅提供答题输入控件，学生被迫使用线下草稿纸，在全屏防作弊与切屏监考模式下，频繁低头演算极易引起视线离开屏幕等误判；
- **目标**：提供轻量、非阻断式内置在线草稿画板（Canvas 演算板），学生可随时在作答页面唤起展开，支持自由手写演算、橡皮擦擦除、多步撤销及一键清空；
- **纯本地留存**：草稿演算过程完全在浏览器端进行，以当前考试 `examId` 为会话隔离键进行本地持久化（`sessionStorage` / `localStorage`），学生在切题、折叠/展开画板或意外刷新浏览器时笔迹无缝恢复，草稿不丢失；交卷完成或退出作答时自毁清理，零后端网络开销、零服务端负载。

## 2. 改动范围与设计细节

### 2.1 零 DDL 与零后端侵入红线
- **纯前端实现**：`src/main`、`src/test`、`pom.xml`、`schema.sql`、`docker/mysql/migrations/` **0 字节改动**；
- **契约保持不变**：`openapi.yaml` 100 paths 严格保持不变；
- **门禁基线**：后端 714 / 0 / 0 / 1 保持不变，`.github/ci/gate-baseline.json` 仅单调上调 `frontendTests`。

### 2.2 核心前端组件与交互设计
1. **画板挂载与悬浮交互（`frontend/src/components/student/ScratchpadCanvas.vue` 与 `student/exams/[id].page.vue`）**：
   - 仅在考试作答期间呈现（`!closedByBackend && !submitResultView`）；
   - 提供界面右侧/浮动操作栏「📝 草稿板」快捷开关，点击展开/收起悬浮面板；
   - 悬浮面板支持半透明背景或适度阴影，避免完全遮蔽题目核心题干，支持最小化折叠。
2. **Canvas 演算功能**：
   - **画笔模式（Pen）**：支持多档粗细（细 2px、中 4px、粗 8px），支持常用对比色切换（黑 `#222222`、红 `#ff4d4f`、蓝 `#1890ff`、绿 `#52c41a`）；
   - **橡皮擦模式（Eraser）**：清除画布上指定轨迹；
   - **历史撤销（Undo）**：维护操作快照栈，支持按笔画步骤逐步回退撤销；
   - **一键清空（Clear）**：快速重置画布，重置前可撤销或具备状态防呆。
3. **作答会话级持久化与自毁**：
   - 本地键规则：`exam_scratchpad_${examId}`；
   - 无论学生在答题卡中如何切换题目、折叠画板或误刷新页面，画布笔迹即时保存并自动回填恢复；
   - 交卷成功（`submitResultView` 激活）或学生确认交卷后，自动清理本地缓存。

## 3. 变异验证预设（两项必检闭环）

1. **变异 m1（本地持久化与恢复破坏）**：
   - 注入点：在画板初始化加载逻辑中，移除从本地存储（`sessionStorage`/`localStorage`）中恢复笔迹快照的逻辑，或将恢复数据置空；
   - 预期击红：测试断言「页面刷新或重载后已存草稿能够正确恢复至 Canvas 上下文」断言级失败（`expected restored canvas data but got empty`）。
2. **变异 m2（一键清空或撤销历史破坏）**：
   - 注入点：在一键清空逻辑中跳过画布上下文清除或未同步清空历史记录栈；
   - 预期击红：测试断言「执行一键清空后画布处于空白状态且笔画计数重置」断言级失败。

## 4. 门禁与交付基线
- 后端门禁：仓库根目录 `./mvnw.cmd clean test` 保持 714/0/0/1 全绿；
- 前端门禁：`pnpm test` 必须全量通过，用例数从 917 上调至 917 + N（预计净增约 6~10 个测试用例）；
- OpenAPI 契约：100 paths 保持不变。
