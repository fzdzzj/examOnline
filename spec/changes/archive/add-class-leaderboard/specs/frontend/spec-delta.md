# frontend 规范增量（add-class-leaderboard）

## 变更概述

学生「单场考试逐题回顾」页新增班级匿名榜单区块：匿名前 10（脱敏姓名、总分、名次）+ 本人行高亮；空态与后端 404 语义一致。

---

## 新增的 Requirement

### Requirement: 班级匿名榜单展示

WHEN 学生在单场考试逐题回顾页查看班级榜单,

系统 SHALL 以榜单区块展示匿名前 10（脱敏姓名、总分、名次）与本人行高亮；本人不在前 10 时 SHALL 在榜尾展示本人名次；无成绩或未发布时 SHALL 展示与后端 404 语义一致的空态文案。

#### Scenario: 榜单渲染与本人高亮

GIVEN 榜单接口返回 top 与 myRow

THEN 渲染名次 / 脱敏姓名 / 总分列表

AND isMe 行高亮且实名

#### Scenario: 空态

GIVEN 接口返回 404 语义

THEN 展示空态文案（如「暂无本人成绩记录」），不渲染榜单骨架

AND 空态与逐题回顾页既有空态文案风格一致
