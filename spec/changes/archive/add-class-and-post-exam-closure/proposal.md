# 提案：班级体系 + 考后闭环（阶段 9，缺考 + 补考 + 成绩复核）

## Why

主链路（出题→组卷→考试→交卷→判分→成绩发布）已闭环，但对照真实考试系统，缺失一个关键地基与三段考后业务：

1. **班级体系缺失（地基）**：`User` 无班级归属字段，`Exam.classId` 是悬空 ID（注释"班级实体后续阶段提供"但一直未建）。这导致「应考名单」无法确定——缺考判定、补考名单筛选都依赖它，是当前最大的数据模型空洞。
2. **缺考标记缺失**（§8.10 已决策）：考试结束后无法识别"应考但未点击开始"的学生。
3. **补考/缓考缺失**（§5.1/§8.2/§12.5 已决策）：缺考/低分学生无法被指定补考，成绩规则无法配置。
4. **成绩复核缺失**（§5.4/§10.7 已决策）：学生端"部分批改可走复核"是死链接，无申请/处理/反馈闭环。

这四块合起来构成**「考试闭环的最后一公里」**——从"交卷"到"成绩确认"之间，真实系统里必然存在的组织单元（班级）与异常处理（缺考/补考/复核）。

**背景（均已决策，见 `docs/需求决策记录.md`）**：
- §8.10 缺考定义：时间窗结束仍未点击开始 = 缺考，记录缺考状态，缺考学生可被教师筛选指定补考。
- §12.5 补考数据建模：补考是**独立考试记录**（独立时间窗/时长/规则），与主考互不影响。
- §8.2 补考对象：教师按分数筛选（缺考/未交卷/低于分数线）后勾选指定。
- §5.1 补考/缓考成绩规则：按考试配置，取最高分 / 取最近一次 / 取平均分；历史成绩保留不覆盖。
- §12.6 学生转班：转班成绩随人，历史成绩跟随学生个人（答卷已绑 student_id），报表按当前班级统计。
- §10.7 成绩复核限制：每场考试限申请 1 次，成绩发布后 7 天内可申请。
- §5.4 复核期间显示：复核中隐藏成绩，显示"复核中"，防止"看了分数再申请"。

**当前状态**：无班级实体/关联、无缺考概念、无补考、无复核；成绩发布后学生只能看分数，无异议渠道。

**期望状态**：教师建班、学生入班/转班；考试绑班级自动推导应考名单；考试结束自动标记缺考；教师筛选缺考/低分名单指定补考（独立考试 + 成绩规则）；学生可对已发布成绩限次限时申请复核，复核中隐藏成绩，处理完成后更新显示。

## What Changes

- **班级体系（地基）**：
  - `classes` 表（id/name/course_id/teacher_id/created_by/...）；
  - `user_class` 关联表（user_id/class_id/joined_time；转班 = 更新 class_id，成绩随人无需迁移）；
  - 班级 CRUD、学生入班/移除/转班（教师/管理员权限）。
- **应考名单推导**：考试绑 class_id → 应考名单 = 该班级当前学生（user_class 查 class_id）。
- **缺考标记**：考试状态机"进行中→已结束"时，应考名单 − 有答卷者 = 缺考，写 `exam_absence`（exam_id/student_id/status/marked_time）。
- **补考**：
  - 补考是独立考试记录（复用 exams 表 + 关联主考 `parent_exam_id`）；
  - 教师按主考成绩筛选（缺考/未交卷/低于分数线）→ 勾选指定 → 生成补考名单（`exam_candidates` 限制可进入学生）；
  - 补考成绩规则字段（takeHighest/takeLatest/takeAverage）；
  - 历史成绩保留，按规则取最终成绩。
- **成绩复核**：
  - `score_review` 表（exam_id/student_id/status/reason/result/apply_time/handle_time/handler_id）；
  - 限 1 次（唯一索引 exam_id+student_id）、7 天内（apply_time 校验）；
  - 复核中隐藏成绩（学生端返回"复核中"），处理完成更新显示。

## 风险

- **应考名单推导依赖班级数据完整性** —— 缓解：缺考标记仅在考试结束时对"当前班级学生"做差集，历史转班学生以答卷为准不受影响。
- **补考成绩规则与既有成绩汇总冲突** —— 缓解：补考是独立考试记录，成绩规则在"取最终成绩"阶段（成绩发布/汇总时）按考试配置合并，不污染主考答卷。
- **复核隐藏成绩的并发**（申请与发布竞态）—— 缓解：复核申请用唯一索引幂等，隐藏逻辑读"是否有进行中复核申请"，与成绩发布状态机正交。
- **范围偏大** —— 缓解：分 4 个子阶段交付（班级→缺考→补考→复核），每阶段独立验收。
