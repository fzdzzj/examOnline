# frontend spec-delta：试卷抽题矩阵蓝图模式（add-frontend-paper-blueprint）

## ADDED Requirements

### Requirement: 试卷抽题矩阵蓝图模式

教师在试卷详情页（`teacher/papers/[id].page.vue`）的随机抽题区域 SHALL 支持在「规则列表」与「矩阵蓝图」两种抽题模式间并列切换。
在矩阵蓝图模式下：
1. 矩阵行数据源为题库标签，教师可从标签选择器勾选要纳入蓝图的知识点标签；
2. 矩阵列为难度（简单=1、中等=2、困难=3）；
3. 矩阵单元格为题量输入框（`InputNumber`），空或 0 SHALL NOT 生成规则；
4. 矩阵底部 SHALL 提供覆盖度摘要行，仅合计各非空单元格题数之和；
5. 蓝图抽题编译：每个非空单元格编译为一条 `Rule{tagIds:[该行标签], difficulty:列值, count:格值}`，`type` 不设；
6. 校验拦截：未勾选标签或全部单元格为空/0 时，点击预览抽题 SHALL 予以警告拦截，SHALL NOT 向后端发送抽题请求；
7. 抽题流程复用：编译结果复用既有 `previewDraw` 预览与 `commitRandomDraw` 确认入卷，入卷成功后重置蓝图输入；
8. 三态处理：标签查询失败 SHALL 以错误 Alert 显性呈现并隐藏矩阵数据区；题库无任何标签时 SHALL 呈现「题库尚无标签，请先在题库管理中创建并打标」空态提示；预览或入卷失败呈现既有后端 400 错误信息；
9. 零回归：既有「规则列表」抽题模式的功能、交互与规则录入校验保持零改动。

#### Scenario: 抽题模式切换与蓝图矩阵渲染

GIVEN 教师在试卷详情页切到「随机抽题」页签

WHEN 切换抽题模式为「矩阵蓝图」并勾选知识点标签

THEN 渲染双向细目表矩阵，包含所选标签行、易/中/难三列题量输入及覆盖度合计行

AND 切换模式时作废旧预览结果

#### Scenario: 蓝图规则编译与多格抽题

GIVEN 教师在矩阵蓝图中配置了多个知识点在不同难度下的题量

WHEN 点击「预览抽题」

THEN 系统按标签顺序与难度升序将非空单元格编译为规则列表并提交 previewDraw

AND 题型 type 不设，空格与 0 被忽略

#### Scenario: 未选标签或全部单元格为空时拦截

GIVEN 教师在矩阵蓝图中未勾选任何标签，或已选标签但所有单元格题量均为空或 0

WHEN 点击「预览抽题」

THEN 前端拦截并给出警告提示

AND 不向后端发送预览请求

#### Scenario: 题库无标签空态提示

GIVEN 题库中尚无任何标签数据

WHEN 教师切到「矩阵蓝图」模式

THEN 界面呈现「题库尚无标签，请先在题库管理中创建并打标」空态提示

AND 不渲染标签选择器与矩阵表格

#### Scenario: 标签查询失败显性呈现且数据区隐藏

GIVEN 标签列表接口查询失败

WHEN 教师切到「矩阵蓝图」模式

THEN 错误 Alert 显性呈现错误原因

AND 矩阵数据区隐藏

#### Scenario: 既有规则列表模式零回归

GIVEN 教师在随机抽题页签处于「规则列表」模式

WHEN 进行规则添加、题型/难度/标签选择、移除与预览

THEN 既有规则校验与抽题行为完全保持不变
