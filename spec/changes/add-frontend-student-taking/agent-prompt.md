## 硬约定（违反即返工）

1. **本阶段不改后端**：`src/main/**`、`src/test/**`、`pom.xml`、`openapi.yaml`、`docker/**` 零改动。接口缺口一律**停下回报**，不许前端拼凑绕过、不许 mock 冒充、不许手写契约类型。
2. **倒计时以服务端时间为权威**：见核实第 1 项。**本地归零只做两件事：锁定作答界面 + 标记「待同步」**，网络恢复后按锁定状态提交；**最终超时判定在后端**。禁止用本地时间决定是否允许交卷、禁止在前端计算「已超时所以不给交」。
3. **交卷结果以后端返回为唯一权威**：**禁止**用前端本地标记（localStorage / 内存 flag）代替后端结果判定「已交卷」。弱网下那样做会造成「前端说交了、后端没收到」，学生成绩丢失。
4. **交卷防重是配合而非替代**：点击提交后按钮立即 pending 并禁用、超时自动交卷与手动交卷**走同一提交函数**（不许两份逻辑）。但**权威仍是后端三重幂等**，前端不做「本地标记已交卷就不再发请求」这种替代。代码注释写明这条分工。
5. **交卷失败必须保留答案并允许重试**，**禁止静默丢弃**、禁止清空表单、禁止把失败当成功。
6. **自动保存不得改成「每次按键即保存」**：后端是按 30s 草稿 + 5000 并发压测设计的。输入用防抖，**防抖间隔不得小于后端设计假设**；定时保存周期用常量。擅自加密保存频率等于给后端造一个它没被压测过的负载模式。
7. **草稿合并方向必须保守**：后端草稿与 IndexedDB 本地缓存冲突时，**以时间戳 / `version` 较新的一方为准**；**无法判定新旧时，保留两份并提示学生，绝不静默覆盖学生答案**。合并逻辑必须是纯函数且有 vitest 单测覆盖三个分支（后端较新 / 本地较新 / 无法判定）。
8. **切屏只警告 + 记录，不强制交卷**（`docs/需求决策记录.md` 既有决策：是否作废由教师事后依据行为日志判定）。**禁止**实现「切屏 N 次自动交卷」。
9. **只上报能确证的事件**：`visibilitychange` 与 `blur` 在多标签 / 最小化 / 系统弹窗下语义不同。**禁止**虚报事件类型、**禁止**为了凑数把一次失焦拆成多条、**禁止**自行抬高 `severity`。
10. **界面极简**：题目导航（已答 / 未答 / 当前）+ 上一题 / 下一题 + 四种题型作答控件。**不做**计算器、**不做**标记备注、**不做**草稿画板（用户已裁决：画板默认不做，若要做属独立立项 `add-frontend-scratchpad`）。
11. **不声称离线考试模式**：IndexedDB 只服务于「断线期间不丢答案 + 恢复后同步」。**禁止**引入 Service Worker 做完整离线作答，**禁止**在文案 / 注释 / 回报里写「支持离线考试」。
12. **不夹带**：人脸识别、设备指纹、IP 白名单、浏览器锁定（全屏强制 / 禁右键 / 禁开发者工具）——全在 v3 砍掉清单，**一个都不做**。
13. **不夹带后续阶段页面**：不建批改 / 成绩 / 复核页（阶段 23）。交卷结果页只呈现后端已返回的客观题得分与主观题待批改状态。
14. **不引入新依赖**。IndexedDB 用浏览器原生 API 手写薄封装（或**先回报**再考虑极小的库）。**禁止**擅自装 `idb` / `localforage` / `dexie` 等——若你认为确有必要，停下回报说明理由与体积影响，等用户裁决。
15. **质量门禁不许放宽**（不得大面积 `any`、不得关 `vue-tsc` 严格项、不得批量 `eslint-disable`）。
16. **严禁提交** `node_modules/`、`dist/`、`test-results/`、`.env`。

1. **基线自检**：门禁三项 + 后端全量，记录数字。

4. **进入考试**：调进入端点拉个人快照；按后端错误码处理「已有进行中会话」等冲突；**验证刷新后题目集合不变**（这是后端「进入即锁定」的可视化证明，要写进演示脚本）。
5. **极简作答界面**：题目导航（已答 / 未答 / 当前，用纯函数算作答完成度便于单测）+ 上一题 / 下一题 + 四种题型控件（**复用阶段 20 的题型配置驱动做法**，但这是**作答**控件不是**编辑**表单，不要直接复用编辑表单组件）。
6. **倒计时 hook**：
   - 输入：后端给的服务端时间 / 剩余秒数 / 截止时刻；
   - 输出：剩余时长展示、最后 5 分钟警告标志、归零锁定标志；
   - **本地归零 → 锁定作答 + 标记「待同步」**，不自行判定超时；
   - 必须有 vitest 单测：正常倒计时、**服务端与本地时间存在偏移**（模拟学生改本机时间，断言判定仍按服务端）、归零锁定、警告阈值。用假定时器（`vi.useFakeTimers`），**禁止**在测试里真 `sleep` 几十秒。
7. **自动保存 + IndexedDB**：
   - 定时保存周期常量化（按后端 30s 设计假设）；输入防抖；
   - 每次作答同步写 IndexedDB；断线时界面明示「未同步」状态；
   - 重进考试：先拉后端草稿 → 与本地缓存按**保守合并纯函数**合并 → 无法判定新旧时保留两份并提示；
   - vitest 单测：合并三分支、防抖不产生高频请求、断线期间写入本地、恢复后同步。
8. **交卷**：
   - 手动交卷二次确认，**提示未答题数**（用第 5 步的完成度纯函数）；
   - 超时自动交卷**复用同一提交函数**；
   - 点击后按钮立即 pending 并禁用；
   - 结果按后端返回判定；失败保留答案 + 可重试 + 明示失败原因；
   - **重复交卷按后端错误码提示**，不自行判「已交过」；
   - vitest 单测：连点只发一次请求、失败不清空答案、超时与手动走同一路径、后端返回重复错误码时的提示。
9. **切屏检测 hook**：`visibilitychange` + `blur` → 记录次数与时长 → 按核实到的事件类型上报 → **弹警告但不交卷**。vitest 单测：事件触发上报次数正确（**一次失焦一条，不拆分**）、severity 按后端语义、警告不触发交卷。
10. **交卷结果页**：客观题即时出分（后端返回时呈现）、主观题待批改如实展示、**不猜分不预估**。
