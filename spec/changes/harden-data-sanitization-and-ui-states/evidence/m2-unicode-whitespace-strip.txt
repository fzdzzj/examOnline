# m2 变异击红-复原留证：Excel 导入 Unicode 全角空格清洗（stripWhitespace 退回标准 trim()）

规范：M-02 要求 cellText 用 `^[\s\u3000\u00A0]+|[\s\u3000\u00A0]+$` 剥除首尾全部 Unicode 空白；
Java 原生 trim() 仅处理 ASCII ≤ 0x20，不清除 \u3000 全角空格与 \u00A0 NBSP。
变异注入：stripWhitespace 的 replaceAll 改回标准 `text.trim()`，恢复「全角空格导致整行报错」的旧缺陷。
