## 缺陷清单（逻辑级，未修——按判据停下回报）

### D1 试卷题目表不渲染（阶段 20 发现）
- **级别**：逻辑级（组件缺失，功能不可用）
- **现象**：`frontend/src/pages/(dashboard)/teacher/papers/[id].page.vue` 模板使用 `<Table>` 但只 `import type { TableColumnsType }`，漏 import `Table` 组件 → 控制台 `[Vue warn]: Failed to resolve component: Table`，试卷题目表整体不渲染（页面内 `ant_table` 数量 0，卡片 HTML 长度仅 418）。
- **连带影响**：手动组卷的改分/调序/移出入口不存在（20-3b 虽 3×POST 200 但无反馈）；试卷预览看不到题目内容（20-5 部分不成立）。
- **复现**：教师端打开任一试卷详情页即可 100% 复现。
- **引入提交**：`060b012`。
- **建议处置**：另立项修复（补 `import { Table } from 'ant-design-vue'` 一行 + 补一条「页面无组件解析警告」的守卫用例）。

### D2 批改工作台无判分入口（阶段 23 发现）
- **级别**：逻辑级（链路断点，教师纯靠 UI 无法进入批改队列）
- **现象**：`POST /api/exams/{examId}/grading/run` 已生成到 SDK 但没有任何页面调用；批改队列行来自 `subjective_grades` 表，判分前该表无行 → 工作台 `totalStudents=0`、「暂无数据」。
- **连带影响**：教师若跳过判分直接汇总，客观分按 0 汇总（`ScoreService` 不拒绝缺判分数据的答卷）——该分支本轮未实走。
- **复现**：交卷后直接打开批改工作台（不调 grading/run）。
- **建议处置**：另立项（在批改工作台或考试详情加「运行判分」入口；建议同时让汇总对未判分答卷给出可观察的拒绝/提示）。

- **真实窗口焦点切换**：无头沙箱无真实窗口焦点，四种真实手段（另页签/独立浏览器进程/CDP 新窗口/`window.blur()`）实测均无法使 `document.visibilityState` 变化 → 切屏用例以合成 DOM 信号驱动并全程标注。
